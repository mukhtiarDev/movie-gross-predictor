🎥 Movie Gross Revenue Predictor This project implements machine learning models to predict the box office gross revenue of films, focusing on classification (Hit/Flop) and regression (exact revenue) tasks. The goal is to provide a predictive tool for studios to forecast a film's potential commercial success based on pre-release features (e.g., budget, cast, genre, votes).

🚀 Getting Started Follow these steps to set up the project locally.

Prerequisites You need Python 3.8+ installed. All required dependencies are listed in requirements.txt.

Installation Clone the repository: git clone https://github.com/mukhtiarDev/movie-gross-predictor.git cd movie-gross-predictor

Create a virtual environment (recommended):

python -m venv venv source venv/bin/activate # On Windows, use venv\Scripts\activate

Install dependencies: pip install -r requirements.txt

Running the Project The core logic and model training are executed via app.py. python app.py Note: This script will load the data from movies.csv, train the models (Linear Regression, Random Forest, Logistic Regression), and generate the performance evaluation charts seen in the repository.

📁 Project Structure app.py: The main script containing data cleaning, feature engineering, model training, and performance evaluation logic. movies.csv: The dataset used for training and testing the models (contains features like budget, votes, runtime, and the target variable: gross revenue). requirements.txt: Lists all Python packages necessary to run the project (e.g., scikit-learn, pandas, matplotlib). README.md: This file.

📊 Model Performance Highlights The project evaluates both Regression and Classification models, with key findings on their effectiveness:

Regression (Linear): Task: Exact Revenue Prediction. Finding: Accurate for mid-range movies (MAE: $46.44M), but fails on blockbuster outliers.

Random Forest: Task: Hit/Flop Classification. Finding: Best performer with excellent discrimination (AUC = 0.94).

Logistic Regression: Task: Hit/Flop Classification. Finding: Too conservative, resulting in a high number of missed hits 200 False Negatives.

Conclusion: The Random Forest Classification Model is the most reliable tool generated by this project, providing a highly accurate prediction of a movie's class (Hit/Flop).
